# Tutorial

<DownloadCard name="ShadowEmu.exe" href="/downloads/ShadowEmu.exe" size="0.8 MB" />

Shadow Emulator is a **no-restart** tool that lets you launch multiple games without restarting your PC each time.

If you run into issues or support is not available to help you fix them, use the emulator as a **no-restart** solution to make things easier.

<TutorialVideo />

For step-by-step setup, see [How to use](/shadow-emulator/how-to-use) and [Fix Errors](/shadow-emulator/fix-errors).

<div class="gb-notice gb-notice--warning">

**Important**

Avoid spamming the application or triggering resets too quickly. This can cause **VAL-102** errors and rate limits linked to your PC and your Riot account. Wait between attempts and follow the cooldown steps described in [Fix Errors](/shadow-emulator/fix-errors).

</div>
