# Fix Errors

## I get a VAL-5 error after finishing a game. What should I do?

This is normal. At the end of each game, you need to press **F3** and wait 10–20 seconds for the emulator's status to change from "Waiting" to "Connected."

## I got a VAL-102 error. What caused it?

You are spamming the application and the reset cooldown too much, which triggers a rate limit on your access to Riot. Simply wait between **5 and 30 minutes** before trying again. The more you spam and force it, the longer the rate limit will last.

## The application closes suddenly and I can't launch it again. What should I do?

Restart your computer to restore Vanguard to its default version, then launch the emulator again.

## MFA shows "Failed" when I try to use it. What should I do?

Make sure you are in the **lobby** when activating it. You should only use this option when MFA is actually requested — otherwise it is unnecessary and may fail.

## When I launch the app, it tells me to switch applications after an update. What should I do?

Yes — go to the official Discord or check the **Tutorial** section on this site to install the latest available version. Older versions are obsolete. Even if you try to bypass the update, you risk getting banned.
