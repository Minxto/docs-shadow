## Tắt Windows Defender bằng dControl

1. Tải xuống [dControl tại đây](https://www.sordum.org/files/downloads.php?st-defender-control)
2. Giải nén tệp (Mật khẩu: sordum)
3. Chạy dControl.exe
4. Tắt Windows Defender
