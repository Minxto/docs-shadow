## Desativar o Windows Defender com dControl

1. Baixe o [dControl aqui](https://www.sordum.org/files/downloads.php?st-defender-control)
2. Descompacte o arquivo (Senha: sordum)
3. Execute o dControl.exe
4. Desative o Windows Defender
