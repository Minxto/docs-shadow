# Requisitos

## Desactivar Windows Defender con dControl

1. Descarga [dControl aquí](https://www.sordum.org/files/downloads.php?st-defender-control)
2. Descomprime el archivo (Contraseña: sordum)
3. Ejecuta dControl.exe
4. Desactiva Windows Defender
