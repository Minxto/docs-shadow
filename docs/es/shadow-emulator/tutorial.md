# Tutorial

<DownloadCard name="ShadowEmu.exe" href="/downloads/ShadowEmu.exe" size="0.8 MB" />

Shadow Emulator es una herramienta **sin reinicio** que te permite iniciar varios juegos sin reiniciar tu PC cada vez.

Si tienes problemas o el soporte no está disponible para ayudarte a solucionarlos, usa el emulador como solución **sin reinicio** para facilitar las cosas.

<div class="gb-notice gb-notice--warning">

**Importante**

Evita spamear la aplicación o activar reinicios demasiado rápido. Esto puede causar errores **VAL-102** y límites de tasa vinculados a tu PC y tu cuenta de Riot. Espera entre intentos y sigue los pasos de tiempo de espera descritos en [Corregir errores](/shadow-emulator/fix-errors).

</div>
