# 避免游戏封禁

#### **1. 使用优质账户**

* 始终使用具有真实游戏时长的**老账户**。
* 避免新账户或代练账户。

#### **2. 准备您的 PC**

* 如果您之前被封禁，请进行**全新 Windows 安装**（最安全的选择）。
* 启动模拟器前**禁用杀毒软件**。

#### **3. 聪明地作弊**

* 保持**像真人一样**：不要明显的自瞄、不要滥用透视、不要疯狂的连杀。
* 在新账户上先 legit 玩 5–10 小时。
* 不要追求离谱的数据（高 KD、完美命中率等）。

#### **4. 保护您的 IP**

* 任何封禁后更改 IP（重启路由器或使用住宅 VPN）。

#### **黄金法则**

大多数封禁来自**玩家举报 + 人工审核**，而不仅仅是反作弊。越不显眼，您的账户存活时间越长。

### **聪明地作弊 = 账户寿命更长。**
