# 系统要求

## 使用 dControl 禁用 Windows Defender

1. 在此下载 [dControl](https://www.sordum.org/files/downloads.php?st-defender-control)
2. 解压文件（密码：sordum）
3. 运行 dControl.exe
4. 禁用 Windows Defender
