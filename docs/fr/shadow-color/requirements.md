# Prérequis

## Désactiver Windows Defender avec dControl

1. Téléchargez [dControl ici](https://www.sordum.org/files/downloads.php?st-defender-control)
2. Décompressez le fichier (Mot de passe : sordum)
3. Exécutez dControl.exe
4. Désactivez Windows Defender
