# Comment utiliser

## Comment l'utiliser ?

1. Téléchargez Shadow Emulator, installez-le sur votre PC, puis lancez l'application.
2. Rejoignez le serveur Discord officiel (obligatoire), puis copiez et collez votre ID utilisateur Discord dans l'émulateur lorsque demandé.
3. Lisez et acceptez les Conditions d'utilisation, puis sélectionnez votre région.
4. Une fois la configuration terminée, ouvrez VALORANT depuis le Riot Client.

## Comment activer MFA ?

1. Téléchargez Shadow Emulator, installez-le sur votre PC, puis lancez l'application.
2. Rejoignez le serveur Discord officiel (obligatoire), puis copiez et collez votre ID utilisateur Discord dans l'émulateur lorsque demandé.
3. Lisez et acceptez les Conditions d'utilisation, puis sélectionnez votre région.
4. Une fois la configuration terminée, ouvrez VALORANT depuis le Riot Client.
5. Une fois dans le lobby, appuyez sur **F7** pour activer MFA.

## Comment activer No Restart ?

Après chaque partie, lorsque vous revenez au lobby, appuyez sur **F3** et attendez **10 secondes** avant de lancer la file d'attente pour votre prochaine partie.
