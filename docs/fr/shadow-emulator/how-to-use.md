# Comment utiliser

<div class="gb-notice gb-notice--warning">

**Règles**

Avant d'utiliser l'application, lisez les [règles d'utilisation](/fr/rules).

</div>

## Comment l'utiliser ?

1. Téléchargez Shadow Emulator, installez-le sur votre PC, puis lancez l'application.
2. Rejoignez le serveur Discord officiel (obligatoire), puis copiez et collez votre ID utilisateur Discord dans l'émulateur lorsque demandé.
3. Lisez et acceptez les Conditions d'utilisation ; la région sera choisie automatiquement.
4. Une fois la configuration terminée, ouvrez VALORANT depuis le Riot Client.

## Comment activer MFA ?

1. Téléchargez Shadow Emulator, installez-le sur votre PC, puis lancez l'application.
2. Rejoignez le serveur Discord officiel (obligatoire), puis copiez et collez votre ID utilisateur Discord dans l'émulateur lorsque demandé.
3. Lisez et acceptez les Conditions d'utilisation ; la région sera choisie automatiquement.
4. Une fois la configuration terminée, ouvrez VALORANT depuis le Riot Client.
5. Une fois dans le lobby, choisissez la section **MFA Bypass** et cliquez sur le bouton **Bypass**.

## Comment activer No Restart ?

Après chaque partie, lorsque vous revenez au lobby, appuyez sur le bouton **Verify** et patientez **10 secondes**.

<div class="gb-notice gb-notice--danger">

**Note importante**

Plus vous utilisez de logiciels de triche tiers aux côtés de l'émulateur, plus vous vous exposez à des restrictions ou des déconnexions.

</div>
